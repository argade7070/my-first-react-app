# Simple Interest Calculator App

A Java application that calculates simple interest based on user-provided principal, rate, and time.

### Formula

**Simple Interest = (Principal × Rate × Time) / 100**

### Prerequisites

- Java Development Kit (JDK) 8 or higher installed
- Verify with: `java -version`

### How to Run

**1. Compile the Java program:**

```bash
javac SimpleInterestCalculator.java
```

**2. Run the application:**

```bash
java SimpleInterestCalculator
```

**3. Follow the prompts:**

```
========================================
     Simple Interest Calculator App
========================================
Enter the principal amount: 10000
Enter the rate of interest (% per annum): 5
Enter the time period (in years): 3
----------------------------------------
Principal Amount  : 10000.00
Rate of Interest  : 5.00%
Time Period       : 3.00 years
----------------------------------------
Simple Interest   : 1500.00
Total Amount      : 11500.00
========================================
```
